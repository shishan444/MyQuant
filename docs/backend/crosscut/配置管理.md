# 配置管理

## 涉及模块
| 模块 | 影响方式 |
|------|----------|
| api | 配置读写入口，通过 config 路由提供配置查询与更新 API |
| data | 读取 data 相关配置（交易对、周期、历史年限、数据目录） |
| evolution | 读取进化参数（种群大小、代数上限、并行数、早停策略） |
| trading | 读取交易相关配置（实盘交易对、API 密钥） |

## 实现方式

项目采用 **YAML 配置文件 + 环境变量注入** 的双层配置策略，将非敏感的结构化参数与敏感的凭证信息分离管理。

### 全局配置文件

`config.yaml` 是项目的核心配置文件，采用 YAML 格式组织所有运行参数。配置项按功能域分组：binance（交易所凭证）、claude（AI 模型参数）、data（数据源配置）、backtest（回测引擎参数）、evolution（进化引擎参数）。文件由应用启动时加载，各模块按需读取自己关注的配置段。

### 环境变量注入

敏感凭证（API Key / Secret）不硬编码在 config.yaml 中，而是通过环境变量引用的方式注入。配置文件中使用 `${BINANCE_API_KEY}`、`${BINANCE_API_SECRET}`、`${ANTHROPIC_API_KEY}` 等占位符，运行时由配置加载逻辑解析为实际的环境变量值。这确保了凭证不会意外进入版本控制系统。

### 配置读写 API

`api/routes/config.py` 提供配置的 HTTP 读写接口，前端可通过 API 查询当前配置（脱敏后）或更新部分配置项。这使得用户可以在 Web 界面上直接调整回测参数、进化策略等配置，无需手动编辑 YAML 文件。

### 前端配置

前端通过 `web/.env.development` 中的 `VITE_API_BASE_URL` 变量指定后端 API 地址，开发环境与生产环境使用不同的环境文件。

## 配置与约定
| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| binance.api_key | `${BINANCE_API_KEY}` | 交易所 API Key，环境变量注入 |
| binance.api_secret | `${BINANCE_API_SECRET}` | 交易所 API Secret，环境变量注入 |
| claude.api_key | `${ANTHROPIC_API_KEY}` | Claude API Key，环境变量注入 |
| claude.model | - | Claude 模型名称 |
| data.symbols | - | 交易对列表（如 BTCUSDT） |
| data.timeframes | - | K 线周期列表（如 1h, 4h） |
| data.history_years | - | 历史数据回溯年限 |
| data.data_dir | `data` | 数据存储根目录 |
| backtest.init_cash | `100000` | 回测初始资金（USDT） |
| backtest.fee | `0.001` | 交易手续费率（0.1%） |
| backtest.slippage | `0.0005` | 滑点率（0.05%） |
| evolution.population_size | `15` | 每代种群个体数 |
| evolution.max_generations | `200` | 最大进化代数 |
| evolution.early_stop.patience | `15` | 早停耐心值（连续无改善代数） |
| evolution.early_stop.min_improvement | `0.5` | 早停最小改善阈值（%） |
| evolution.early_stop.decline_limit | `10` | 早停连续下降上限（代） |
| VITE_API_BASE_URL | `http://localhost:8000` | 前端 API 基础地址 |

## 源码锚点
- [→ config.yaml] 全局配置文件，所有运行参数集中定义
- [→ api/routes/config.py] 配置读写 API 路由，支持查询与更新
- [→ web/.env.development] 前端开发环境配置，VITE_API_BASE_URL 定义
