# 动态定仓组间配对对照表

> complete-research-tooling 任务 5 交付物（P10 初值实施终定）。
> 消费方：研究者（理解参数组合语义）与审查（行为基准）。

## 大白话总起

风险预算制定仓（position_mode=risk_budget）只回答一个问题：第一笔仓位开多大。它按「愿意亏多少钱」反推数量——用当時账户权益乘以风险比例，除以止损位到入场价的距离。这份对照表把这一新参数与其他三个仓位相关参数（加仓比例、总敞口上限、部分离场比例）组合时的语义逐行说清：以前这三者只跟固定比例仓共存，现在多了风险预算档，组合规则是初值建议的实施终定，测试与规格以本表为准。

## 对照表

| 组合维度 | 语义（实施终定） | 行为锚 |
|---|---|---|
| risk_budget × add_fraction | **首仓制**：风险预算只管首仓；加仓仍按 add_fraction 固定比例（分母=当時权益，0.4.2 R3 原语义不变）——不引入「每笔加仓也按风险预算」的复合公式（复合公式在部分离场后基数歧义无法自洽，初值裁决=不加复合） | 引擎 add 分支不读 position_mode——risk_budget 与 fixed 的加仓路径同构 |
| risk_budget × max_exposure | **全局取严**：首仓名义敞口上限=min(leverage, max_exposure)×当時权益（与既有 max_exposure 语义同域——总敞口约束对两种定仓模式一视同仁）；超限截断数量到上限并计数 orders_capped | _risk_budget_qty 公式内 cap 计算；重放计数同款 |
| risk_budget × exit_fraction | **比例不变**：部分离场按 exit_fraction 比例平当前仓位（0.4.2 R3 原语义不变）——部分离场不动仓位基数，后续重入场再按 risk_budget 重算首仓 | reduce 分支不读 position_mode |
| risk_budget × stop_loss（前置依赖） | **公式分母**：risk_budget 声明时必须同时声明 stop_loss>0（登记面与 validate_dna 面双拒）——止损距离是仓位公式的分母，无止损=风险预算不可定义 | hypothesis_service 组合校验+validator 组合校验 |
| risk_budget × risk_fraction（前置依赖） | **比例本体**：必须同时声明 risk_fraction∈(0,0.5]（上界=社区惯例单笔风险不超过半成权益的保守上界） | 同上双面校验 |

## 三档止损距离分派（首仓公式内）

| sl_mode | 止损距离 | 数量特征 |
|---|---|---|
| pct | 入场价×stop_loss | 距离宽度固定 → 数量恒定（与 fixed 数值可等价，见 V4b 容差锚） |
| atr | stop_loss×当根 ATR | 逐笔随波动变——波动大则仓位小 |
| trail | stop_loss×入场 bar ATR（初始追踪距离） | 逐笔随波动变 |
